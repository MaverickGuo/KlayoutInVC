# 需求文档（当前迭代）

更新时间：2026-03-09
版本基线：v0.1.0

## 1. 范围与目标

本轮针对 VS Code 内 GDS 查看体验，聚焦以下问题：

1. `label` 不能渲染。  
2. `cell` 列表顺序混乱。  
3. 缺少测距能力。  
4. 缺少网格与比例尺。  
5. 图层配置只能逐个点选，效率低。  
6. 文档不足，跨工作区（非全局）启用方式不清晰。  
7. 对后端进程留存、内存回收机制缺少说明。  

## 2. 需求清单（逐条）

### R1 Label 渲染

- 目标：在版图中显示文本 shape（label/text）。  
- 当前状态：已实现。  
- 验收标准：打开含文本的 GDS，在视图中可见文本；可通过“标签: 开/关”切换。  

### R2 Cell 字典序

- 目标：Cell 下拉列表按字典序（含数字自然排序）展示。  
- 当前状态：已实现。  
- 验收标准：`cell1, cell2, cell10` 排序符合预期，不再乱序。  

### R3 测距工具

- 目标：支持两点距离测量，并可吸附到已显示图形边缘。  
- 当前状态：已实现。  
- 验收标准：点击两点后显示距离；状态栏同步显示测距值；可清除测距；在边缘附近取点时自动吸附；开启测距后光标切换十字准星。  

### R3.1 测距正交约束

- 目标：按住 `Shift` 时，测距终点只能沿水平或垂直方向约束。  
- 当前状态：已实现。  
- 验收标准：`Shift + 测距` 时，第二点相对第一点只改变 `x` 或 `y`。  

### R4 网格与比例尺

- 目标：增强定位和尺度感知。  
- 当前状态：已实现。  
- 验收标准：视图上能看到网格线和右下角比例尺，缩放后动态变化。  

### R5 图层批量操作

- 目标：减少逐层点击成本。  
- 当前状态：已实现。  
- 验收标准：支持按关键字筛选图层；支持全选/全不选/反选。  
- 规则：有筛选关键字时，批量操作只作用于当前筛选结果。  

### R5.1 图层排序

- 目标：图层列表按字典序稳定展示，降低查找成本。  
- 当前状态：已实现。  
- 验收标准：图层展示顺序按 `L{layer}/{datatype} {name}` 字典序排列（数字按自然顺序）。  

### R6 文档与启用方式

- 目标：明确当前状态和非全局启用流程。  
- 当前状态：已实现。  
- 验收标准：新成员按文档可在任意工作区独立启用，不影响全局。  

### R7 后端留存与内存回收

- 目标：避免后台进程长期残留和内存无限增长。  
- 当前状态：已实现基础保障。  
- 验收标准：关闭编辑器后后端进程退出；空闲超时自动退出；缓存有上限。  

### R8 渲染性能

- 目标：降低拖拽/缩放时卡顿与后端重复算图开销。  
- 当前状态：已实现（第一阶段）。  
- 验收标准：交互过程中保持可视预览；停止交互后快速恢复高清渲染；重复/相近视图请求复用缓存。  
- 实现点：
  1. 前端交互模式使用低分辨率、低多边形、禁标签预览渲染。  
  2. 前端渲染队列改为单飞请求，避免并发堆积。  
  3. 后端按量化视图 key 做 SVG LRU 缓存。  
  4. 交互阶段使用 `fast` 样式，静止后切回 `hatch` 质量渲染。  

### R9 LYP 导入

- 目标：从 KLayout `.lyp` 批量带入图层名称/可见性/颜色映射。  
- 当前状态：已实现（基础映射）。  
- 验收标准：点击 `导入LYP` 后，匹配到的 layer 能更新名称；可见性同步到勾选状态；色块更新。  

### R10 图层名称手动编辑

- 目标：在 layer map 侧边栏直接改图层名（处理默认空名场景）。  
- 当前状态：已实现。  
- 验收标准：可直接在图层行内输入名称并生效于筛选；重开文件后仍保留。  

## 3. 关键功能使用说明

### 3.1 图层批量筛选怎么用

1. 在左侧“图层”面板顶部输入筛选关键字。  
2. 关键字可输入 `layer/datatype` 或 layer 名称片段，例如 `67/20`、`M1`。  
3. 点击 `全选`、`全不选`、`反选` 进行批量操作。  
4. 如果筛选框非空，按钮只影响“筛选出来的图层”；清空筛选后影响全部图层。  

### 3.2 测距怎么用

1. 顶部工具栏点击 `测距: 关`，切成 `测距: 开`。  
2. 进入测距模式后，画布光标会变成十字准星，移动时会进行吸附预览。  
3. 左键点击第一个点（若靠近图形边缘会自动吸附）。  
4. 再左键点击第二个点，完成测量（同样支持边缘吸附）。  
5. 如果要强制水平/垂直，按住 `Shift` 再取第二点。  
6. 距离会显示在量测线旁和状态栏。  
7. 点击 `清除测距` 可清空。  
8. 重新点击 `测距: 开` 按钮退出测距，光标恢复普通状态。  
9. 测距模式下左键用于取点，平移请用中键拖拽。  

## 4. 本轮剩余风险

1. 大规模版图仍是整帧 SVG 渲染，极端密度场景可能卡顿。  
2. 未支持 `.lyp` 层组树和完整线型语义（当前仅基础映射）。  
3. 测距目前只支持两点直线距离。
